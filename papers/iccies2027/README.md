## Compile

The paper must be built with **XeLaTeX**, because the Vietnamese examples use
tone-marked letters (`lủ`, `nhục`, `sủa`, `mẹ`) that live in Unicode's Latin
Extended Additional block. pdfLaTeX with T1 cannot typeset them: it reports
"Unicode character ... not set up for use with LaTeX", drops the letter, and its
Computer Modern default needs 17 pages instead of the 15 allowed. As a guard,
`main.tex` raises an explicit `PackageError` when it is compiled with pdfLaTeX
instead of producing a silently broken PDF.

The bundled `latexmkrc` sets `$pdf_mode = 5`, so the plain latexmk call that
editors use by default already selects XeLaTeX:

```powershell
latexmk main.tex
```

Equivalently, `latexmk -xelatex main.tex`, or the manual sequence:

```powershell
xelatex main
bibtex main
xelatex main
xelatex main
```

`main.tex` also starts with `% !TEX program = xelatex` for TeXstudio,
TeXworks and LaTeX Workshop.

Every font comes from the TeX distribution: the body is **TeX Gyre Termes**, a
metric-compatible Times clone shipped with TeX Live and MiKTeX, so no system
font is needed and Windows and Overleaf produce the same PDF; mathematics stays
in the class's Computer Modern, and the two figures are PDFs with their fonts
embedded. For Overleaf: upload this folder and set *Menu → Compiler → XeLaTeX*
(Overleaf ignores `% !TEX` magic comments), and nothing else needs installing.

Output: `main.pdf`, 15 pages, no BibTeX warnings.

## Overleaf

Upload the whole folder — `main.tex`, `latexmkrc`, `llncs.cls`,
`splncs04.bst`, `references.bib`, `sections/`, `tables/`, `figures/` — then set
*Menu → Compiler → **XeLaTeX***. Two symptoms mean the compiler is still
pdfLaTeX, and both come from the same cause:

| Symptom | Cause |
| --- | --- |
| 16–17 pages instead of 15 | Computer Modern/T1 instead of Times |
| `Unicode character ⋯ not set up for use with LaTeX`, accents missing from the case-study and cue-taxonomy tables | T1 has no Vietnamese glyphs, so `lủ`, `nhục`, `mả` are dropped |

Overleaf runs TeX in nonstopmode, where `\PackageError` alone is not fatal, so
`main.tex` also issues `\stop` on the pdfLaTeX branch: a wrong compiler now
gives one explicit error and *no PDF at all* instead of a plausible-looking
17-page one. Check the first line of the log: it must read `This is XeTeX`, and
the PDF must have 15 pages.

## Numbers and provenance

Every quantitative claim is generated by

```powershell
$env:PYTHONIOENCODING = "utf-8"
python scripts/47_iccies_numbers.py
```

which reads the frozen artefacts under `outputs/evaluation/` and writes
`outputs/evaluation/fusion/iccies2027/{numbers.json,paper_numbers.md}`. The script
asserts that the rule scores shipped with the fusion predictions are identical to
the tuned rule-engine output; the primary system is
`sensitiveai-vi-custom` + `fusion_per_channel_thresholds`
(`alpha_H=0.1`, `alpha_O=0.8`, `alpha_C=1.0`; `tau_H=0.07`, `tau_O=0.58`,
`tau_C=0.60`).

## Substituting content

- **Model:** results are for `sensitiveai-vi-custom`. To switch to another
  backbone, update `tables/backbones.tex`, `tables/fusion_variants.tex`, the
  case-study rows in `tables/case_studies.tex`, and the per-channel paragraph in
  `sections/results.tex` from `outputs/evaluation/fusion/iccies2027/paper_numbers.md`.
- **Examples:** comments in `tables/case_studies.tex` and
  `sections/analysis.tex` are masked with `*`. Keep the masking when editing.
- **Page budget:** the file is tuned for exactly 15 pages under the LNCS class with
10pt TeX Gyre Termes and the class-default `\small` bibliography. There is about
one line of slack, so if you add text, shorten a paragraph of equal length or the
bibliography will push the count past the limit.
